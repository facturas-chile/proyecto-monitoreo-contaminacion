# Librerías Requeridas

Instalar desde el **Library Manager** del Arduino IDE (Herramientas → Administrar bibliotecas):

| Librería | Autor | Versión mínima |
|---|---|---|
| **WiFiNINA** | Arduino | 1.8+ |
| **ArduinoHttpClient** | Arduino | 0.4+ |
| **DHT sensor library** | Adafruit | 1.4+ |
| **ArduinoJson** | Benoit Blanchon | 6.x |
| **EEPROM** | Arduino (built-in) | — |

> **Nota:** `DHT sensor library` de Adafruit requiere también instalar `Adafruit Unified Sensor`.
